# New England Anime Society Website

A simple, elegant single-page website for the New England Anime Society (NEAS), a 501(c)3 non-profit organization.

## Features

- **Single-page infinite scroll design** - All content on one page with smooth scrolling
- **Minimal framework usage** - Pure CSS and vanilla JavaScript
- **Responsive design** - Works on all devices

## File Structure

- `index.html` - Main HTML file
- `styles.css` - All styling (no CSS frameworks)
- `script.js` - JavaScript for smooth scrolling and form handling
